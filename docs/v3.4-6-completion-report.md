## 11. 团队留言

v3.3.0 → v3.6.0 = 3 个 minor release / 14 个 commit / 4 个 fail-fix CI 循环 /
17.39s 跑完 241 测试。

最大收获：
1. **设计教训显式落地**：每个 v3.x 路线图项都对应一个 commit + 测试 +
   文档，从 v3.2.5 文档"承诺"变成代码"事实"
2. **fail-fix 循环 = 真理生成器**：workflow #3 Windows + #11 nextest 都是
   本地 100% 全过但 CI 真实环境 fail 的案例；这印证 v3.2.5 §26.4
   "代码会暴露文档无法预见的问题"
3. **PIPE_DEFS preflight ≠ runtime bin 的设计 v3.5 进一步泛化**：jest /
   cargo / cargo-nextest 各自有自己的 runtime 路径，设计统一吸收
4. **国内网络的真实痛点必须内化进工具**：v3.4 region detect + mirror_config
   不是"功能补全"，是"对用户的承诺" — 在 Spike-2 实测时被 brew
   USTC 镜像卡 20min+ 的真实经历

下一步推荐：**让团队 review v3.4-v3.6 14 个 commit + 12 次 CI 跑分历史**，
基于反馈再启 v3.7。AGENTS.md 已沉淀本会话所有决策，下一次 AI 会话不
需要从头读 git log。
