## 7. v3.3 已增补 / Spike 中发现的工程问题

| # | 问题 | 修复 |
|---:|---|---|
| 1 | go-junit-report v2 默认 `<testsuite name="">` 为空 | `<system-out>` JSON events fallback 解析 Package |
| 2 | `-set-exit-code` flag 让 junit_proc 继承测试失败 | junit_ok 判定改用 XML 落盘 + 可解析 |
| 3 | pip --user pytest 不在 PATH | preflight_pipe 支持 `python -m pytest` alt_bins |
| 4 | jest 在 fixture 内 `./node_modules/.bin/`，不在 PATH | PIPE_DEFS `runtime_bin` 字段分离 |
| 5 | cargo stdout 混编译信息 + JSON | 过滤 `{...}` 开头/结尾的纯 JSON 行 |
| 6 | stable Rust 不允许 `-Z unstable-options` | `RUSTC_BOOTSTRAP=1` 启用 |
| 7 | cargo2junit 对空 stdin 输出空 `<testsuites/>` 假成功 | actual_targets=[] 时 pipeline_ok=false |
| 8 | 企业内网 nexus 让 mvn 拉不到依赖 | fixture `.mvn/maven.config` + `settings.xml` 用阿里云镜像 |
| 9 | Java 26 + Maven 3.9.9 restricted method warning | 不影响功能，文档化兼容性 |
| 10 | 国内 brew install 卡 USTC 镜像 20min+ | 改用 archive.apache.org / aliyun 直接下载二进制 |
| 11 | git status --porcelain 折叠 untracked 目录 | `git diff --name-only` + `git ls-files --others` 组合 |
| 12 | Windows cp1252 解码中文 stderr 失败 | `PYTHONUTF8=1` 环境变量 + subprocess 显式 encoding="utf-8" |
| 13 | shared_evidence scope 简单 head segment 误判 | `_static_prefix` + 严格 prefix 包含判定 |
